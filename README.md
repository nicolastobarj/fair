# FAIR Experimental Study

The effect of transparency in automated and AI systems on users’ trust, understanding, and decision-making: An experimental design testing prototypes in the public sector

## Repo Structure

```
├── data: Databases information required to prepare processing, analysis, presentations, and articles:
│
├── proc: Scripts for database processing.
│
├── report: Files generated from QMD scripts to explore the data.
```

## Reports

- [Field Work Report](https://nicolastobarj.github.io/fair/report/a_field_work_report.html): Información acerca de los tiempos de respuesta, Attention checks y validación de las respuestas.
- [Eliminated distribution](https://nicolastobarj.github.io/fair/report/b_distribution_eliminated.html): Definición de criterios para eliminar casos considerados no-validos, y distribución de casos eliminados.
- [Construct validation](https://nicolastobarj.github.io/fair/report/c_construct_validation.html): Métricas de validación de los constructos y sus distribuciones.
- [Bivariate analyses](https://nicolastobarj.github.io/fair/report/d_bivariate_analyses.html): Correlaciones y pruebas T entre las variables de intervención y las dependientes.
- [Manipulation Check](https://nicolastobarj.github.io/fair/report/e_man_check_models): Exploración de los Manipulation Check.
- [Hypotheses models](https://nicolastobarj.github.io/fair/report/f_hypotheses_models.html): Modelos de regresión con las hipótesis principales.
- [Moderation models](https://nicolastobarj.github.io/fair/report/g_moderation_models.html): Modelos de regresión con las variables de moderación por hipótesis.
